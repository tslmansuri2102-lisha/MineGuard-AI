# MineGuard AI — ML Data Dictionary

## 1. Overview & Integration Context

This document serves as the authoritative ML Data Dictionary for the **MineGuard AI** project during **Phase 0 — Integration Contracts Setup**.

It defines all input, derived, and output fields required by the Machine Learning (ML) inference engine, model training pipelines, and explainability modules (`feature/ml-ai-data`), establishing strict compatibility with `API_CONTRACT.md`.

---

## 2. Data Source Classification

Every data field in the pipeline belongs to one or more of the following classifications:

- **`REAL DATA`**: Measurement values captured directly from physical deployed sensors, weather stations, or geotechnical bench surveys.
- **`SYNTHETIC DATA`**: Data generated by physics-based geotechnical models or numerical slope simulators for testing and model bootstrapping prior to physical deployment.
- **`IoT DATA`**: Real-time environmental or geomechanical telemetry streams received from ESP32/IoT edge hardware or simulators.
- **`GIS/DEM DATA`**: Spatial, topographical, and morphological attributes extracted from Digital Elevation Models (DEM) or drone photogrammetry.
- **`DERIVED DATA`**: Features calculated during the feature engineering stage (e.g., rate of displacement, acceleration, moving averages).

> [!NOTE]
> Synthetic data generated during development must strictly adhere to the data types, units, and ranges specified below.
